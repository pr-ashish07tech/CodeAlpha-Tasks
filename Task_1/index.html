    About

    धुन is a Music player. Pick a song from the playlist, save the ones you love to Favorites, and keep listening on Spotify, YouTube Music or JioSaavn from the links above.

    FAQ

    A song is not playing. Why?

    Each song plays from its own file in the songs folder, named like kesariya.mp3. If the file is missing, the player shows "Audio file not found".

    How do I add my own songs?

    Tap "Add songs from device". Files are matched to songs by name (Kesariya.mp3 plays as Kesariya). Unmatched files are added as new songs.

    Are my favorites saved?

    Yes. They stay in this browser after you refresh the page.
